# IntakeOps Technology Radar

## Adopt

Technologies and patterns currently used.

- Structured outputs
- Zod validation
- Prisma
- PostgreSQL
- Context engineering
- Human-in-the-loop review
- Event-driven workflow states

## Trial

Things approved for limited experimentation.

- Tool calling
- Evaluation datasets
- Prompt and context versioning
- Background processing

## Assess

Things worth monitoring but not yet approved.

- MCP
- Hybrid retrieval
- Prompt caching
- Context compression
- Workflow orchestration platforms
- LLM harness patterns

## Hold

Things intentionally not being adopted.

- Multi-agent swarms
- Autonomous irreversible actions
- LangChain solely for abstraction
- Vector search where bounded context is sufficient

## Evaluation Criteria

A technology enters the roadmap only when it:

1. solves a real IntakeOps problem
2. improves employability
3. reflects production practice
4. provides enough value to justify complexity
