# IntakeOps Roadmap

## Product Goal

IntakeOps turns incoming client feedback, requests, and project updates into structured actions, risks, priorities, and draft responses.

## Current Capabilities

- Client feedback event ingestion
- Prisma + PostgreSQL persistence
- Workflow states
- Structured AI processing
- Context engineering
- Human review
- Dashboard aggregation
- Retry and failure handling

## Current Phase

Context-aware client operations workflow.

## Completed Milestones

### v0.1 — AI Processing
- Structured feedback analysis
- Risk detection
- Suggested responses

### v0.2 — Event-Driven Workflow
- Event ingestion
- Workflow states
- Persistence
- Retry handling

### v0.3 — Context Engineering
- Project context
- Context builder
- Scope assessment
- Human review reasoning

## Next Priorities

- Evaluations and regression testing
- Tool calling
- External integrations
- Observability
- Production reliability

## Deferred

- Authentication
- Multi-tenancy
- Gmail integration
- MCP
- Multi-agent orchestration
- Large-scale document retrieval

## Review Policy

The roadmap is reviewed after each major module and may change based on:
- IntakeOps product needs
- production AI practices
- employability value
- architecture complexity
